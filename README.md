# digital

Digital Store - Premium Digital Products Marketplace

## Features
- Modern e-commerce design
- Product catalog with filters
- Shopping cart functionality
- Order management
- Integrated Zanderio AI chatbot
- Responsive design
- Payment integration (EasyPaisa, JazzCash)

## Technologies Used
- HTML5
- CSS3 (Custom styling)
- Tailwind CSS
- JavaScript (Vanilla)
- Zanderio AI Widget

## Setup
1. Clone the repository
2. Open `index.html` in your browser
3. Start shopping!

## Live Preview
Open `index.html` directly in any modern web browser.
